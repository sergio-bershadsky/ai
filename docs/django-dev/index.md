# Django Dev Plugin

Opinionated Django development toolkit with Ninja API, Unfold admin, pytest, Dynaconf, uv, and Docker patterns

## Installation

```bash
/plugin marketplace add sergio-bershadsky/ai
/plugin install django-dev@bershadsky-claude-tools
```

## Skills

- `django-dev`
- `django-dev-ninja`
- `django-dev-test`
- `django-dev-unfold`

## Agents

- `django-review`
