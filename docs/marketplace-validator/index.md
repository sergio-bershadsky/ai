# Marketplace Validator Plugin

Validates marketplace.json schema after every edit in this repository

## Installation

```bash
/plugin marketplace add sergio-bershadsky/ai
/plugin install marketplace-validator@bershadsky-claude-tools
```

## Hooks

- `PostToolUse` → validate-marketplace.py

Full reference: [plugins/marketplace-validator/README.md](https://github.com/sergio-bershadsky/ai/blob/main/plugins/marketplace-validator/README.md)
