# Tortoise Dev Plugin

Enterprise Tortoise ORM (async Python) toolkit: one-model-per-file in models/ subpackage, abstract Base interfaces for mocks/transitions, strict class layout, FastAPI lifespan, built-in Tortoise migrations (Aerich-free), Pydantic v2, pytest patterns

## Installation

```bash
/plugin marketplace add sergio-bershadsky/ai
/plugin install tortoise-dev@bershadsky-claude-tools
```

## Skills

- `tortoise-dev`
