# Diagramming Plugin

Polished dark-themed architecture diagrams as self-contained HTML+SVG. Includes design system, Bezier-correct label placement with clean-background priority, halo text, leader lines, and audit + coordinate-shifter scripts.

## Installation

```bash
/plugin marketplace add sergio-bershadsky/ai
/plugin install diagramming@bershadsky-claude-tools
```

## Skills

- `architecture-diagram`
- `architecture-diagram-react`
- `mindmap`
- `sequence-diagram`

Full reference: [plugins/diagramming/README.md](https://github.com/sergio-bershadsky/ai/blob/main/plugins/diagramming/README.md)
